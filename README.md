D&D Campaign Wiki

A console-based D&D campaign wiki built with Python and SQLite.

Features:
- Manage NPCs
- Manage player characters
- Manage factions
- Manage quests
- Manage locations
- Manage NPC–Faction relationships
- Manage Quest–Location relationships

Technologies
- Python
- SQLite

Current Status:

The basic database structure and CRUD functionality are implemented.

The project is currently being expanded with additional relationships and features.

This is a work in progress.
